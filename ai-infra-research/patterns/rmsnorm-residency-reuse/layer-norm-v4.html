LayerNormV4 · 使用与扩展




价值


两组 FP32 都沿 R=16 归一化。A=65,536 时，Host 选 Transpose（800），NDDMA 将 X 搬入 RA，并在首块写回前预取尾块。A=28,672 时恰好落在每核 512 行的阈值，Host 选 Two-Pass Perf（500），在单个 UB tile 内保存中心化 X 供仿射复用。


使用


  1. 切换左下角配置，点选或播放源码步骤。点亮的 Tensor 和 UB 区间对应当前步骤。
  2. 展开「缓冲生命周期」查看逻辑偏移与占用范围，打开「硬件映射」查看当前步骤在 AIV 中的逻辑路径。
  3. 右上「核查」串联 Host 断言、tiling 计算和 Kernel 派发。「当前选择」可复制或导出证据，「源码」可切换 Kernel、Host tiling、单测与派发。






扩展


新增配置时，先核对 Host 分支和对应 Key，再推导实际 tile、InitBuffer 与 Kernel 使用区间。接入 Ascend 950 设备 Trace 后可核对步骤时序、搬运重叠及耗时。
