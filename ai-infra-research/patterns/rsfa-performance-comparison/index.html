比较口径
点越靠左，耗时越少。比率 = 当前实现耗时 / 同路径、同 case 的对照耗时；1 表示相等。收益 = 1 − 比率。
线段 = [当前 min / 对照 max, 当前 max / 对照 min]。它描述已观测范围的保守包络，不是置信区间。跨越 1 时，单次测量的胜负可能翻转；不跨越 1 也不保证跨设备、跨轮次稳定。
门槛只筛选实际收益，不代表统计显著性。原始样本不按序配对；序号不是时间戳。median 从已舍入的 times_ms 重算，源 avg 保留原值。
数据包含 30 条记录、600 个样本；JSON 时间戳 2026-07-16T04:05:59.360283，未给时区。BM/BN 按记录展示，比较包含 tiling 变化，不能分离为融合本身的因果收益。
同提交 README 声明 910B3 / FP16；当前 runner 已改为五个版本命名，与此 JSON 的 baseline/fused/fused_split 不一致，不能证明它就是这批数据的生成脚本。硬件环境及正确性没有在本机复测。
