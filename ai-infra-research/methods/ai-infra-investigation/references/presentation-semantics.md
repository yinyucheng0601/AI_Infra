# 呈现语义契约

沿用 [任务契约](task-contract.md) 的 case、对象 ID、证据引用、选择和交接。写清用户问题、当前范围、必要证据、缺失时的反馈和完成判据。对本次任务写一份小型映射表，已有等价 schema 可直接复用。同一份领域对象和证据可供多种呈现模式读取。

| 交接 | 适用路径 | 最小约定 |
|---|---|---|
| 定位对象 | 结构呈现／对照、交互调查 | 记录稳定对象 ID、定位目标、配置与适用范围。 |
| 核查依据 | 结构呈现／对照、交互调查 | 记录来源类别、证据引用、成立条件和缺口。按需绑定 revision、运行实例及时间区间；分开工程证据、推断与任务执行状态。 |
| 操作上下文 | 交互调查 | 定义触发条件与发起时所需的 case、对象、版本、配置、证据和问题。 |
| 结果更新条件 | 交互调查 | 写清更新哪个对象和字段，何时生效。用动作 ID 记录发起请求，分别维护执行进度、工程判断和用户选择。按发起上下文归档，核对对象、范围和版本后更新。缺证据保留待验证反馈，执行失败仅更新执行状态，错上下文留档并禁止更新结论。较早请求迟到时保留更新后的判断。 |

| 模式 | 最小呈现要求与任务验收 |
|---|---|
| 机制讲解 | 写出解释顺序、各步可定位的对象或关系、关键前提和支持来源。读者能据此解释一次机制变化。 |
| 结构浏览 | 写出层级或导航范围、同一对象在不同尺度的定位、返回位置和核查依据。读者能从总览找到细节并返回。 |
| 实验对照 | 写出对齐键、共同基准、指标单位、样本或时间窗与不可比条件。读者能核查每一列的来源，未知和不可比项明确呈现。 |
| 交互调查 | 逐步走通定位、核查、继续调查、结果返回。核对发起快照、写入条件、未知和失败反馈。 |

以上交付独立于组件。实现阶段再用同一份契约绑定组件的读取对象、交互与状态。

## 界面绑定

Timeline 使用来源明确的顺序与尺度；TraceView 使用运行实例、时间单位与事件区间；Inspector 读取当前对象与证据；Diff 写清对齐键和比较口径；Action 声明触发前提、交接内容和可用结果。按任务启用，可组合多个组件。记录主辅视图、坐标和尺度、对象关联、颜色含义，以及默认、选择、布局切换和返回时的状态。

静态页面在构建时绑定对象和证据，预设结果明确标为回放。接入真实 Agent 的示例见 [候选复核](candidate-review.md)。
