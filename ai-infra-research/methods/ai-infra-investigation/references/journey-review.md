# 联合操作路径验收

用于已生成的交互调查工具。每项记录通过、失败或未验证及证据；根据任务跳过不适用步骤，不为走完流程伪造异常或添加控件。项目的浏览器授权和预览限制优先。

| 路径 | 核查内容 |
|---|---|
| 进入默认视图 | 页面骨架符合已确认参考；主体优先，身份、配置、控制与内容分离；忽略解释文字后结构仍可辨 |
| 理解对象 | 关键对象的输入、输出、执行归属或存储绑定有证据支持；Task、Kernel、Instruction 等类型准确；没有孤立组件靠长标签补关系 |
| 发现调查入口 | 可主动推导候选时提供入口；没有候选时呈现覆盖范围和未知项，不制造告警；简短用途与证据边界在 Info 可发现 |
| 选择普通与边界对象 | 关联对象及读数一致；颜色保持原语义；切换 shape 真正重算，选择不重置用户视角 |
| 核对候选 | 列表保持位置和顺序；选中详情在其后，范围与单位明确；模型、参数与设备观测的证据层级不混淆 |
| 操作控件 | 同一任务的配置与定位合理分组；状态读数与按钮可区分；无效分页隐藏或禁用；菜单、图标和焦点符合组件规范 |
| 查看提示与浮层 | 一个控件仅一套 tooltip，键盘也可达；面板按约定锚点打开、随内容适配高度，最大高度后内部滚动；展开/关闭不挤压主图 |
| 查源码、导出、返回 | 源码对应当前对象与固定版本；问题、预览和导出一致；关闭、返回及缩放后选择与视角按约定保持 |

先修骨架与关系，再修密度、控件和材质。自动测试分别证明模型、脚本或交接一致性；真实布局、遮挡、命中面积与光学表现须另记渲染证据。用户评审可以作为用户确认记录，不改写成自动化验收。

修改已收录条目时同步原型、收录产物、来源指纹与封面；检查卡片到最终页面的链接。远端发布仍以本次授权为准。
