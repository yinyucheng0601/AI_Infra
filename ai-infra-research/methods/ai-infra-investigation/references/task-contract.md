# 阶段交接契约

以下是最小信息约定，不是现成可调用的诊断 API；项目已有等价 schema 时直接复用。case 泛指当前任务：模型配置、编译快照、部署配置或 trace 均可。shape/axes/accesses 仅在对应任务适用；编译任务补快照与变换对应，部署任务补设备/分组，运行任务补事件与时间单位，不为满足表格伪造无关字段。

| 信息 | 必需字段或含义 | 负责层 |
|---|---|---|
| case | 稳定 ID、repo/revision、shape/dtype/axes/stride、用户问题 | 领域 |
| objects | 稳定 ID、类型、逻辑坐标、单位、分组与有效范围 | 领域 |
| mappings | from/to ID、关系类型、表达式、条件、证据 ID | 领域 |
| accesses | 请求槽、目标槽、消费/写回标志；未知项不填推测值 | 领域 |
| evidence | 文件、行范围、固定 revision、可核查表达式、推导条件 | 领域 |
| glyphs | 对象类型、正式 item/variant、renderer/SVG 来源及哈希 | 图元 |
| selection | case、当前对象/步骤 ID、关联对象；与 viewport 分离 | 工作台/界面 |
| handoff | 当前选择、问题、配置、参数、证据与未确认项 | 工作台 |
| validation | 检查性质、方法、覆盖范围、结果、未验证部分 | 各层 |

数学集合、源码请求集合和实测观测不是一种状态值。映射可标为 confirmed-source / conditional / unknown；实测另附采集来源，不能从前者自动升级。额外请求是集合差异，不自动标为错误。

序列化与预览使用同一内容生成器；切换选择后 context 变化，pan/zoom 不改变对象身份。检查器展示当前对象自身属性，关联输入的地址不混称输出属性。

完成判据：普通和边界对象能沿这条链追溯；独立参考检查映射；选中对象对应源码；复制内容与预览及用户问题一致。布局可读性需真实渲染检查，静态脚本不能替代。新 shape 不被验证前保持固定案例声明。

空间调查工作台额外验收：记录已定稿参考及继承的画布/控制/浮层机制；检查平移、指针缩放、fit、普通与边界选择、浮层开关后视角保持。主体全视口且与控制组件分离；忽略解释性文字后关联仍可辨。骨架不符合用户确认的布局，设计验收失败，局部排版或数据检查不能抵消。
