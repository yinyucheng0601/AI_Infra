# 首次任务与复用

下面以算子调查作最小示例；总 workflow 也可接受模型计算、编译变换、并行部署或真实 trace 任务，并按领域路由取用证据，不要求每次都展示索引与尾块。

## 生成调查视图的 prompt

```text
分析 [算子仓库 / 算子 / 用例]，我想核对 [具体索引或布局疑问]。
使用 ai-infra-investigation workflow；AI_Infra checkout 位于 [本地路径]。
先读项目约束，固定版本，不修改算子、不安装设备环境。
核对当前生效分支、数学集合与源码请求，复用正式图元和已有交互。
先做普通与边界对象的映射，未知 API 标出缺口，不预先认定 bug。
生成可操作页面，点选后关联源码，可复制问题与证据。
独立验证覆盖、遗漏、重复和交接内容，分别说明未验证部分。
```

只提供库中的 Skill 文件时，按本环境支持的方式直接读取；不假设用户已经安装其他 Skill。完整 workflow 组合包应提供六个目录，checkout 则提供全部入口和原型。安装位置遵循所用客户端当前文档，不写死本机路径。

## 从图回到调查

用户点选输出/搬运组，填写疑问并复制上下文。agent 应先核对条件与 API 约束，说明确定事实、还缺证据与最小验证方案。是否修改代码由任务授权决定，不把可视化标记当错误判决。

## 从案例走向复用

先用 Case05 集成参考核查链路，再用另一合法 shape 检查同一适配器，随后迁移第二实现。转置适配置换；Gather/Scatter 适配间接索引和重复/冲突。通用映射方法不等于已有适配器覆盖所有 API。
