# 视觉与交互验收

将每项记录为通过、失败或未验证；不得把未验证记作通过。评审任务只报告，不自行修复。

## 必须修正

- 数据：单位、来源、范围、采样与聚合方式可识别；未知不等于零；无装饰性因果关系。
- 编码：同一值跨视图色标一致，选择不覆盖数值含义，异常与普通选择可同时识别。
- 构图：默认视图的真实主体边界处于合理视觉中心；文字不遮挡主体，关键端点未被裁切。
- 层级：当前对象、名称与辅助参数形成清晰尺度对比，避免所有元素等权；局部紧凑、区域间留白。
- 交互：点击后选择持久，检查器可操作，开关不造成主图无意位移；返回能恢复上下文。
- 导航：范围、当前点和异常可辨，目标可点击或键盘选择，不能仅靠不可触达的小刻度操作。
- 可读性：计算实际前景/背景组合的对比度，普通文字以 4.5:1、大字以 3:1 为验收目标；必要交互边界与图形标识以 3:1 为目标。装饰分隔线可以更淡，但不能承担唯一识别功能。不要仅凭 token 声称达标。
- 可访问性：选择和异常有非颜色提示，键盘焦点可见，无 hover 唯一入口，减少动态效果时仍可完成任务。
- 适配：窄屏无关键内容溢出或控件相互遮挡，必要时转底部抽屉或全屏检查。

## 检查方法

在实际运行页面中检查至少一个目标桌面尺寸和一个窄屏尺寸；记录使用的尺寸。查看总览、选择、检查器打开与关闭后的截图，操作缩放、返回整体和键盘入口。检查浏览器错误及按钮真实行为，不把无功能控件当作已实现。

按“数据正确性—构图—层级—精修”顺序修复后重新渲染。视觉不合格包括主体偏移、同权卡片过多、所有文字相近大小、线条抢过数据、检查浮层遮住选择目标等；以实际画面判断，不靠 CSS 声明推断。

无法预览时明确交代仅完成代码或静态检查，列出未验证的视觉与交互状态。不要绕过环境限制。
