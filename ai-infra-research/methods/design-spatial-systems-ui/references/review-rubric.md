# 视觉与交互验收

将每项记录为通过、失败或未验证；不得把未验证记作通过。评审任务只报告，不自行修复。

## 必须修正

- 数据：单位、来源、范围、采样与聚合方式可识别；未知不等于零；无装饰性因果关系。
- 编码：同一值跨视图色标一致，选择不覆盖数值含义，异常与普通选择可同时识别。
- 构图：默认视图的真实主体边界处于合理视觉中心；文字不遮挡主体，关键端点未被裁切。
- 层级：当前对象、名称与辅助参数形成清晰尺度对比，避免所有元素等权；局部紧凑、区域间留白。
- 交互：点击后选择持久，检查器可操作，开关不造成主图无意位移；返回能恢复上下文。
- 导航：范围、当前点和异常可辨，目标可点击或键盘选择，不能仅靠不可触达的小刻度操作。
- 可读性：计算实际前景/背景组合的对比度，普通文字以 4.5:1、大字以 3:1 为验收目标；必要交互边界与图形标识以 3:1 为目标。装饰分隔线可以更淡，但不能承担唯一识别功能。不要仅凭 token 声称达标。
- 可访问性：选择和异常有非颜色提示，键盘焦点可见，无 hover 唯一入口，减少动态效果时仍可完成任务。
- 适配：窄屏无关键内容溢出或控件相互遮挡，必要时转底部抽屉或全屏检查。

## 空间画布专项

- 控件：小控件使用 control（折射 -110、色散 0/4/8、4px 模糊、28% 深色背板）；面板使用 panel（折射 -12、无色散、18px 模糊、94% 深色背板）；独立圆按钮使用 icon。检查实际背景下的折射与文字读取，不用普通 blur 冒充完整效果。文字图标不降透明度，组件各自的选择态、hover 和焦点可辨（互斥切换与菜单项不共用一套强制选中样式）；非 Chromium 回退须与完整效果区分记录。
- 组织：同一任务的主操作合理集中，缩放独立，辅助工具遵循项目锚点；无重复摘要、遗留分隔符和相互遮挡。图标按钮有 tooltip、可访问名称和正确状态。
- 遮挡（体块聚焦视图）：后方和无重叠体块保持深灰实体，只有覆盖高亮对象的前景体块整体为 25% opacity；顶面不过亮，无逐面白色透明叠加。切换选择和调整布局后重新判断。
- 关系标签：每个高亮行或轴标注一次，沿外侧连线延长段排列，方向随连线，无遮挡和裁切。

## 控件与面板检查

- 图标使用统一 SVG 语言，不以字符代替；配置菜单的当前项、hover、焦点及键盘操作明确。
- 同一目标只出现一套 tooltip；检查原生 title、自定义提示和祖先元素，覆盖动态控件及键盘聚焦。
- 状态读数不伪装成可点击操作；范围含义明确，无效分页不占据默认操作区。
- 面板短内容时无空白撑高，长内容到最大高度后内部滚动；按约定锚点打开；展开、切换及窄屏状态不挤压主体。
- 若有核查列表，选择前后列表保持在详情之前，选中项、对应图形、源码与交接一致。

## 检查方法

在实际运行页面中检查至少一个目标桌面尺寸和一个窄屏尺寸；记录使用的尺寸。查看总览、选择、检查器打开与关闭后的截图，操作缩放、返回整体和键盘入口。检查浏览器错误及按钮真实行为，不把无功能控件当作已实现。

按“数据正确性—构图—层级—精修”顺序修复后重新渲染。视觉不合格包括主体偏移、同权卡片过多、所有文字相近大小、线条抢过数据、检查浮层遮住选择目标等；以实际画面判断，不靠 CSS 声明推断。

无法预览时明确交代仅完成代码或静态检查，列出未验证的视觉与交互状态。不要绕过环境限制。

## 定稿页面增量验收

- 对照 [增量设计与修复流程](approved-ui-and-repair-flow.md)，检查是否改变已批准的导航与交互。
- 一张决策卡内分组，不按行拆卡；图元优先填充且跨方案对齐；无文字阴影。
- 告警附着对象且不被线遮挡；选择页可直接比较结构、绑定、结果；应用后才更新结果。
- 实心卡片不套玻璃；blur 如被明确要求，只作用于有填充的真实边界。

- 颜色串用：选择/关联是否使用宿主已确认 token；无约定时是否为中性近白；是否误把绿色图元或成功状态当通用交互高亮。
