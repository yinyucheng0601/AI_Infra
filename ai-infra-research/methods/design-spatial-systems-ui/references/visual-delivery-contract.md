# 可视化交付契约

## 职责与选择

领域规则决定对象、集合、地址、依赖和证据边界；Spatial Systems UI 决定整体布局与外围交互。结合使用时不继承讲解报告的分页、封面或常驻说明。用户要求调查工具时，先定义一条最短操作路径：选择对象 → 看关联 → 查证据 → 继续调查。无需为小改动重新制定计划或请求审批。

## 资产入口

先核对项目当前已确认资产与 Skill 随包快照；版本不一致时记录具体来源，不凭视觉印象混用。为使用的图元记录 variant、renderer、依赖及来源指纹。直接调用 renderer 或复用原始 SVG，仅修改暴露的参数。颜色相同不算图元复用。旧 renderer 不得覆盖已确认的新版本；来源变化应触发复核，而不是构建时静默接受。

对象语义与图元映射要可检查：抽象 Tensor 与逐元素矩阵不同；测试用例、tiling 参数和 Kernel 入口不自动成为数学 OP。OP 显式选择已有类别；未知类别不得默认套 Linear 图标。缺口保留为候选，不自动新增正式图元。

renderer 负责内部几何、标签与图标，layout 负责位置、分组、端口和连线。宿主 CSS 不覆盖图元内部字体与标签结构。对使用的 variant 检查必要特征，例如叠字 Tensor 的标签在 grid 内、类别 OP 包含 badge/icon。不要将这些特征强加给采用其他约定的图元库。

## 先验证一条链

选择普通与边界各一个真实对象，把选择、映射、检查、导出做通，再扩展全部数据。确定性数据模型独立于渲染，共享稳定对象 ID 与选择状态。数学应有集合、源码访问集合与实测结果分别表示；源码顺序不能伪装成实测时间。

## 验收层次

- 数据：用独立参考检查合法性、覆盖、遗漏和重复；解释重复访问的语义。
- 图元：验证实际生成的 SVG/DOM 及来源指纹，不能仅检查函数或文件存在。
- 行为：默认状态有可发现的操作入口；选择联动不重置视角；面板按约定打开、移动、缩放；导出与可见预览及用户问题一致。
- 视觉：在交付文件上检查默认、普通、边界、证据展开状态。文字包围盒、遮挡、命中面积需要真实渲染验证，静态或 VM 检查不能替代。浏览器验证遵循项目许可，未验证的项目明确保留。

仅重复验证受改动影响的契约；一次性局部 UI 调整不要求全量回归。不要把某个案例的坐标、按钮材质、固定面板位置或提示卡提升为所有项目的规则。

## 既有 Demo 改造的证据边界

改造前按 [迁移流程](demo-visual-migration.md) 盘点并消融，使用共享组件契约；发现同类缺陷时检查相关动态实例及其他视图。交付将代码检查、浏览器交互、合并、部署与线上验证分别记录为通过、失败或未验证。诊断结论不等于已修复，部署成功不等于线上交互通过；局部修改只要求复验受影响契约。

## 分层约束

用户和项目的明确要求优先。其余选择按下面三层约束执行，并在实现前记录各层的来源和适配点。

| 层级 | 约束强度 | 实施与验收 |
| --- | --- | --- |
| 控件与外壳 | 最强，按已确认的组件契约执行 | 直接复用共享的按钮、工具栏、面板、菜单、提示及其 token。核对图标和顺序、尺寸和内外间距、材质、选中与焦点、键盘行为、开关与返回状态。宿主只负责组件允许配置的定位、文案和回调。通过组件源或共享 token 修改样式，由消费方同步生成；局部 CSS 不覆盖已确认的控件默认值。 |
| 内容与联动 | 优先复用完整 Pattern；用户指定 Pattern 时，相关模块和代表操作是必选项 | 复用业务模块的呈现结构、图元、坐标轴口径、对象联动和展开方式。先匹配正式入口和数据契约，再挂载 renderer。例如同轴 UB 生命周期图保留图和步骤联动，硬件映射保留窗口与路径逻辑。跨算子替换数据、标签和证据，通过 Pattern 参数调整范围。 |
| 领域数据与证据 | 按新案例独立求证 | 用当前源码、配置或 Trace 生成对象和关系，重新核对条件、字节、步骤与证据引用。每类数据的展示能力取决于实际证据。 |

找不到控件实现、Pattern 接口或必要输入时，登记缺口及影响范围，沿用其余可用能力。更换已指定的模块形式或交互，需先和用户明确这项变化。最终验收分别记录控件契约、Pattern 的代表操作和领域数据证据。

## 指定参考页的 UI 验收

实现前为每个被点名的组件记录参考页、实现来源、当前状态以及要保持的结构和交互。将材质、尺寸、间距和选中填充写成明确值或共享 token。只在数据、内容或用户指定样式处增加适配；组件替换需先说明影响。

交付前打开参考页与最终入口，在同一视口、主题、配置和控件状态下对照。对按钮与面板检查渲染尺寸、间距、`backgroundColor`、`borderWidth` 和 `backdropFilter`，核对展开、折叠、拖动、关闭与视角保持。角标数字要与打开后直接可见的同级项数一致。面板预设断言采用 [Liquid Glass](liquid-glass.md) 的共享值，并检查是否被宿主覆盖。记录实际测量、并排观察及未执行的验证。

涉及独立 HTML、Pattern 收录或 Skill 分发时，检查生成后的入口和包内资产。优先复用同一组件和 token 源，令构建同步副本。只看源模板、DOM 属性或组件名称不能证明最终样式一致。

## 工程证据视图实现

读取通过校验的领域模型与呈现语义契约，保留作用域引用、语义色、证据等级与未知项。离线视图可由所选对象返回源码定位或原始 Trace 字段；界面变化不导致对象换绑。验证资产路径、选择、键盘焦点、缩放和核查面板。实际运行记录与静态检查分别登记。
