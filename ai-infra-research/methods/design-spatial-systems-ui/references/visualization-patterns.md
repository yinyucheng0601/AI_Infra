# 主体形式的选择与适配

按问题选择形式，不按视觉偏好强制转换数据。

| 观察问题 | 形式 | 总览与细节 | 必须保留 |
|---|---|---|---|
| 数量比较与趋势 | 2D 图表 | 总览读趋势，选择后读精确值 | 单位、范围、真实变化，不任意平滑 |
| 二维分布与块结构 | 矩阵/热力图 | 总览读分布，放大后显网格与数字 | 行列身份、采样说明、跨视图一致色标 |
| 依赖与数据流 | 拓扑/节点图 | 总览读主路径，展开后读属性 | 方向和关系类型；无依据不画因果 |
| 层级、空间与内部组成 | 2.5D/3D | 总览读结构，剖切/展开后读局部 | 深度语义、对象身份、遮挡处理 |
| 执行顺序与持续时间 | 时间轴/泳道 | 总览读并行关系，缩放后读事件 | 真实时间比例、重叠、间隙；不能简化成等距导航 |
| 多对象探索与证据组织 | 无限画布 | 总览读分组关系，聚焦后操作原生图表 | 返回焦点、范围定位、可追溯连接 |

## 桌面构图

为主体建立连续空间，身份信息与状态信息形成疏密不同的组。用最大字号表达当前有意义的身份或指标，不强制给每个页面制造大编号。允许对象局部裁切用于聚焦，但总览不得隐藏关键端点、异常或必要数据。

对于无限画布，只在初始适配和用户明确“返回整体”时自动居中；用户平移、缩放和选择后保持其视角。对于长时间轴，优先保证可读时间范围，不要求内容完整塞入视口。对于比较任务，可用并列视图和共享坐标，不强制单一视觉中心。

## 交互状态

Hover 为临时预览，selection 为持久身份，inspector 为可操作细节，三者独立维护。检查器关闭后保留当前选择；沉浸视图退出后恢复进入前的视角与缩放。提供明确关闭、键盘焦点和触控入口。

主体与检查器共享对象 ID、数据来源和选区范围。检查器不会因指针离开触发区域消失。没有可用空白时，改用可返回的全屏检查，避免压住待比较的数据。

## 数据与样式冲突

选择轮廓和异常标记必须叠加到数据编码之外；不要把热力图数值直接改白表示选中。简洁导航仅负责定位，不能替代用户需要的 RMS 比较或事件持续时间分析；统计可按需展开，但入口必须保留。

使用深度淡化时仅处理辅助轮廓和标签，不改变数据色阶。保留领域特有图元、箭头和线型，不将所有节点统一成普通 UI 控件。
