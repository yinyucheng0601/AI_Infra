# 既有 Demo 视觉迁移

适用于已有可运行可视化的视觉改造、跨算子迁移和批量图元替换。保留领域模型、对象身份与有效交互；参考页面提供视觉契约，不提供可直接套用的领域依赖。局部小改动只检查受影响部分。

## 1. 盘点与消融先于样式

实际打开原版及参考，列出信息、控件、对象、图元、状态、事件、相机及动态生成入口。为各项标记保留、合并、删除或替换。以用户任务判断独立能力：重复摘要、重复详情入口、无效返回、嵌套 Tab 和遗留分隔符优先合并或删除；必要的取消、返回及参数能力保持可达。尊重定稿结构和本次授权，不借消融删除有效分析能力。

组织信息时区分全局身份、对象路径、常用筛选、低频配置与解释。当前对象和同级对象切换放在同一上下文；路径后的菜单通常优于独立按钮岛，菜单覆盖完整候选范围。讲解文案不能直接照抄用户参考：先确认对象定义、数量来源、映射规则及证据边界。

## 2. 建立共享契约

| 层 | 实施要求 |
|---|---|
| 画布 | 若目标是无限画布，使用全视口主体与独立 UI 覆盖层；避免整条不透明背板遮挡。实际支持拖拽、滚轮缩放、Fit 和缩放后命中；安全区不等于缩小画布。 |
| 控件 | 复用宿主组件及 Liquid control / panel / icon 预设，一组控件一层材质；检查滤镜对定位、层叠与命中的影响。 |
| 导航 | 算子切换、对象路径和同级切换各有职责；验证切换首帧和加载过程，避免泄露无关页面。 |
| 图元 | 建立领域对象到正式 variant / renderer 的映射；优先共用 renderer，核对类别、徽章、图标比例、文字适配与外部元信息。不能只换外观而丢失事件、命中区、键盘入口和来源关联。 |
| 面板 | 先编辑内容：核心作用 → 关键属性或关系 → 源码依据。标题与正文使用一致背景，不机械罗列重复 What / Kind、空 I/O 或无意义 Evidence。按内容适配高度，超长内部滚动。 |
| 讲解 | 若为可关闭讲解，默认关闭且无残留；开启仅紧凑叠加，不预留布局、不触发 Fit、不改变相机。无独立解释价值的示意图不添加。 |
| 连线 | 根据真实依赖确定端口与路由。采用正交折线时逐类检查起终点、末段方向、箭头朝向、元信息避让及展开状态；折线化不等于连接正确。 |
| 动效 | 保留同一对象跨阶段的位置、身份与上下文；返回恢复合理视野。验证首次加载、后台恢复、暂停条件及减少动态效果策略。 |

## 3. 默认与交互状态分开设计

关系分析画布默认降低非焦点主体的饱和度与视觉强度，hover / 选择恢复对象及必要关系的语义色。数值色标、异常、有效性及承担识别作用的类别编码不得被去色或选择覆盖。Pipeline 可按 Slot / Batch 染色；Graph 连线遵循宿主约定，不强制所有边带彩色。

| 状态 | 职责 |
|---|---|
| hover | 暂态预览当前对象与必要关联；离开恢复持久选择，不写回领域数据。 |
| selection | 持久焦点，驱动详情与跨视图关联；取消路径清楚。 |
| related | 表达与焦点的关系，强度低于焦点，不把整图同色涂满。 |
| status | 表达业务状态或数值含义，与交互高亮独立。 |

状态变化不改变节点位置、宽高或文字布局；透明热区始终透明。检查节点填充、纹理、文字、连线及 marker，避免只改节点留下旧色。选择与焦点遵循宿主 fill 规则，不额外叠加蓝白 border / outline / box-shadow；键盘焦点仍通过填充、标记或文字清楚可辨。菜单可用原 fill 混白约 10%，不要把该数值强加给图形数值编码。

## 4. 先做一条链，再扩展

先用一个普通对象和一个边界对象走通总览 → 选择 → 详情 → 展开 / 切换 → 返回。检查领域派生不变、身份连续及视野保持，再扩展全部对象。跨算子共享控件、图元与状态契约，保留各自依赖和分支；并排对照同类状态，不能以“复用了 CSS”代替验收。

发现一个组件问题后，扫描受影响的同类实例：其他算子、视图、展开节点、动态重绘和键盘路径。不要对无关模块扩大重构。

## 5. 验收与交付

代表状态至少覆盖默认、hover、选择、取消、详情开关、展开和参数变更；按本次改动加入动态菜单、相机或播放生命周期。目标桌面与适用的窄屏采用真实浏览器验证，优先复用项目代表场景。

每项记录通过、失败或未验证及对应证据；代码检查、浏览器交互、PR 合并、部署成功和线上交互分别记录。诊断出的缺陷若未实施修复，不能在发布后自动记作已修复。只重复验证受影响契约；一次针对性修复不要求每次全量回归。
