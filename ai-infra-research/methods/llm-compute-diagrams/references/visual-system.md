# 图元和页面规范

## 配色与排版

沿用参考的中性深色背景 #111111，图解底色 #131313，文字区域 #171717，分隔线 #353535。主文字 #E8E8E8，次文字 #ABABAB；激活 #8CBDFF，参数 #E8C66E，梯度 #BCA3E8。用亮度组织矩阵格子，避免加发光、渐变背景或无意义装饰。正文约 16px、行高 1.8–1.9，解释区标题约 23px；在实际显示比例下检查 SVG 标注的可读性。

桌面正文采用图解和解释两栏，图解通常占 55%–65%。正文区保留标题、完整段落、必要公式和选中图元释义。手机改为图在上、文在下。保持图元尺寸、节点圆角、描边和标签位置一致。

## 图元字典

| 图元 | 语义 | 检查 |
|---|---|---|
| 蓝色方格矩阵 | 激活或动态中间张量 | 标出对象与 shape；与参数区分 |
| 金色方格矩阵 | 可训练参数 | 多矩阵集合要明确概括关系 |
| 紫色方格矩阵 | 对应张量的梯度 | 参数梯度与激活梯度分别命名 |
| 中灰大圆角矩形节点 | 计算操作或折叠模块 | 算子与子层使用明确层级 |
| 圆形 ＋ | 逐元素相加 | 固定为圆形轮廓＋居中加号；输入 shape 一致，合并后 shape 不变 |
| 圆形 × | 逐元素乘法，或标量广播乘法 | 大圆圈内居中乘号；系数和 shape 标在圆外，区别于矩阵乘法 |
| 实线箭头 | 前向数据依赖 | 端点落在真实输入输出上 |
| 紫色虚线箭头 | 反向求导关系 | 朝向上游，标明简写或完整求导图 |
| 设备容器／边界 | rank、设备或 stage | 不与 Layer 容器混淆 |
| 时间事件条 | 某时间轴上的执行区间 | 宽度对应耗时，明确时间单位 |

读取、写回、路由和流间混合系数可能是动态张量，应使用动态数据样式及专门标签。可训练的系数生成参数另外用金色表示。

矩阵函数接受布局边界 w、h 和示意 rows、cols 时，采用 pitch=min(w/cols,h/rows)，cell=pitch-gap；横纵使用同一个 cell，并将 rows×cols 网格居中放入边界。布局边界保持原尺寸，箭头锚点跟随矩阵的实际中心或边缘。注意因果掩码和带数字的混合矩阵可能未经过通用 matrix 函数，也要检查小格比例。

## OP 计算节点的固定样式

Norm、Attention、FFN 等计算节点使用中灰填充 `#505050`、浅灰描边 `#858585`（1.5 个设计单位）、大圆角矩形，圆角半径为高度的一半。文字水平垂直居中，白色 `#FFFFFF`、字重 650；统一尺寸 token：高度 48、字号 18、圆角 24，宽度仅 S=140、M=260、L=360（三档，均为 SVG 设计单位）。同一图中所有 OP 必须保持同高同字号，包括 H_pre、H_res、H_post 和折叠子层；不要沿用 small 字号或总览字号覆盖。长标签选更宽档位或精简显示名称，完整名称放入释义，禁止单独缩小字号或增高。按新尺寸更新连线端点并检查圆角内的文字留白，缩放时整张图等比变化。沿用参考 HTML 的 `box()` 与 `.op`、`.op-label`，所有页面及完整总览共用同一实现。默认不添加右侧展开按钮；保留整节点点击释义。Token 标签、矩阵、容器与圆形 Add 各自保持原有图元。选中／hover 仅调整描边，保持填充与轮廓一致。

## Add 的固定样式与复用

参考 HTML 的图元页为 VISUAL VOCABULARY（含封面时第三页）。其中 `add()` 与 `box()` 是两个独立图元；残差合并和其他逐元素相加均使用 `add()`。圆角矩形用于 Norm、Attention、FFN 等计算模块。Add 的可点击属性由外层 `<g>` 提供，避免用可见的矩形按钮包住加号。

复用参考函数（依赖同一 HTML 的 `group()`、`text()`）：

```js
function add(x, y, key = 'add') {
  return group(key,
    `<circle cx="${x}" cy="${y}" r="19" fill="#111" stroke="#ddd" stroke-width="1.6"/>`
    + text(x, y + 7, '＋', '', 'middle'));
}
```

迁移到其他渲染方式时保留这一几何规范：直径 38 个设计单位、深色填充、浅灰细描边、加号居中。尺寸随整张 SVG 等比缩放；圆形保持宽高相等。标签和 shape 说明放在圆外。连线接到圆周边界，先画线再画节点，避免线穿过加号。需要更大的命中区域时使用透明区域，不能增加可见方框。

选中与 hover 仅改变圆周描边或填充，保持圆形。验收时检查图元页、单子层残差和完整总览中的 Add，以及默认、选中、fit 和放大状态；同时核对蓝／金／紫网格、矩形算子和箭头是否仍使用字典中的样式。文字写着“圆形”并不等于实现已符合，需检查实际 SVG／DOM 和渲染结果；若无法渲染，如实说明验证范围。

## 控件与状态

- 封面独立；唯一底部导航每条 step 上有短标题，并有选中态。页数增加时允许导航横向滚动，切换时只滚动导航自身，避免把整个页面拉到页底。
- info 图标使用按钮语义、aria-expanded，支持外部点击及 Escape 关闭。统一图例、当前页示例声明和使用提示均放在其中。
- SVG 节点关联稳定 node ID 和完整定义；支持点击、Tab、Enter，选中态与右侧释义保持一致。
- 完整图按自身 bounds 计算 fit。放大后拖动查看；区分拖动与点击，防止拖动结束误触节点。用真实视口换算拖动位移，重进页面或按 fit 清除缩放和偏移。
- 桌面完整总览可固定在视口内，文字区独立滚动；画布不出现内层滚动条。小屏正文允许外层滚动。
- 保留明确的缩放按钮；如增加滚轮或触控缩放，说明作用区域并避免无提示地劫持全页滚动。

参考 HTML 中的整体容器、矩阵、节点、info、底部导航及缩放可复用。迁移后检查页面 ID 和图 bounds，移除旧主题文字及过时 CSS 覆盖，而不是不断追加冲突样式。

## Multiply 的固定样式与复用

SwiGLU 的逐元素乘法，以及 MoE 专家输出乘以路由系数，使用独立的圆形 Multiply 图元：直径 48、深色填充 #111111、浅灰描边 #DDDDDD、描边宽 1.6，内部使用清晰的乘号 ×，字号 30、字重 650、水平垂直居中。不要将小号 ⊙ 放进 OP 胶囊或矩形卡片。Add 沿用自身的圆形规范，两者均保持独立的图元函数与圆形交互状态。

圆形 × 在本系列表示逐元素相乘；标量 α 乘向量时说明 α 广播至每个特征。系数、输入输出 shape 及必要标签放在圆外，完整定义放入点击释义。矩阵乘法如 UW、QKᵀ 继续使用明确命名的投影或 MatMul OP，避免与逐元素乘法混淆。公式中的 ⊙ 可以保留数学记法，并说明它对应图中的圆形 ×。

最小 SVG 几何示例（包装到现有可点击 group 中）：

```js
function multiplyShape(cx, cy) {
  return `<circle cx="${cx}" cy="${cy}" r="24" fill="#111111" stroke="#DDDDDD" stroke-width="1.6"/>`
    + `<text x="${cx}" y="${cy}" text-anchor="middle" dominant-baseline="central" style="font-size:30px;font-weight:650;fill:#FFFFFF">×</text>`;
}
```

引入 Multiply 时同步补到独立图例页。检查分步图、系数加权图和总览中的乘法节点，连线落在圆周，选中与等比缩放保持圆形。调整 OP 尺寸后，不能只改节点外观而保留原端点：重新计算进出线锚点，并检查相邻节点间距及外置参数、系数标签的留白。
