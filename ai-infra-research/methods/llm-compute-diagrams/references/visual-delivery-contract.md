# 可视化交付契约

## 职责与选择

领域规则决定对象、集合、地址、依赖和证据边界；Spatial Systems UI 决定整体布局与外围交互。结合使用时不继承讲解报告的分页、封面或常驻说明。用户要求调查工具时，先定义一条最短操作路径：选择对象 → 看关联 → 查证据 → 继续调查。无需为小改动重新制定计划或请求审批。

## 资产入口

先核对项目当前已确认资产与 Skill 随包快照；版本不一致时记录具体来源，不凭视觉印象混用。为使用的图元记录 variant、renderer、依赖及来源指纹。直接调用 renderer 或复用原始 SVG，仅修改暴露的参数。颜色相同不算图元复用。旧 renderer 不得覆盖已确认的新版本；来源变化应触发复核，而不是构建时静默接受。

对象语义与图元映射要可检查：抽象 Tensor 与逐元素矩阵不同；测试用例、tiling 参数和 Kernel 入口不自动成为数学 OP。OP 显式选择已有类别；未知类别不得默认套 Linear 图标。缺口保留为候选，不自动新增正式图元。

renderer 负责内部几何、标签与图标，layout 负责位置、分组、端口和连线。宿主 CSS 不覆盖图元内部字体与标签结构。对使用的 variant 检查必要特征，例如叠字 Tensor 的标签在 grid 内、类别 OP 包含 badge/icon。不要将这些特征强加给采用其他约定的图元库。

## 先验证一条链

选择普通与边界各一个真实对象，把选择、映射、检查、导出做通，再扩展全部数据。确定性数据模型独立于渲染，共享稳定对象 ID 与选择状态。数学应有集合、源码访问集合与实测结果分别表示；源码顺序不能伪装成实测时间。

## 验收层次

- 数据：用独立参考检查合法性、覆盖、遗漏和重复；解释重复访问的语义。
- 图元：验证实际生成的 SVG/DOM 及来源指纹，不能仅检查函数或文件存在。
- 行为：默认状态有可发现的操作入口；选择联动不重置视角；面板按约定打开、移动、缩放；导出与可见预览及用户问题一致。
- 视觉：在交付文件上检查默认、普通、边界、证据展开状态。文字包围盒、遮挡、命中面积需要真实渲染验证，静态或 VM 检查不能替代。浏览器验证遵循项目许可，未验证的项目明确保留。

仅重复验证受改动影响的契约；一次性局部 UI 调整不要求全量回归。不要把某个案例的坐标、按钮材质、固定面板位置或提示卡提升为所有项目的规则。
