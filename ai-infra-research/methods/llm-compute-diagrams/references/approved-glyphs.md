# 当前图元基线 · 2026-10-12

当前复用入口为 `assets/approved-legend-library.html` 与 `assets/approved-glyphs/manifest.json`。SVG 保留正式库当前结果，不包含审核页候选。旧参考 HTML 和 compiler-primitives.js 仅供理解既有实现；与本文件冲突时，以当前基线为准，不自动重写历史定稿报告。

## 使用

1. 按 manifest 的 id、title、family 查找对象。直接复用对应 SVG 的路径、颜色、尺寸比例与笔画；组合时为 defs/marker/clipPath ID 加实例前缀并同步引用，避免多图冲突。
2. 示例名称、shape、数值与数据来源可按任务替换；保留语义。放大缩小时统一缩放，不用拉伸改变矩阵比例。完整 montage 是展示组合，实际布局优先复用其中单个对象。
3. 新样式只在用户请求时迭代。需要评审时保留 Before，未经批准不覆盖当前图元。静态生命周期、数据依赖的两轮改稿未获批准，当前文件是保留原版，不代表新方案已验收。
4. SVG 与来源说明可内嵌到独立 HTML；核心图形不依赖外部文件。检索、详情与 SVG 导出沿用库内实现。

## 已确认视觉与语义

- 数据的稳定身份、表示方式与角色分别理解。折叠值、矩阵、数值向量、角色、KV cache、分块状态、异常采样、灰度采样集中为一个家族。展示库内使用页面原有等尺寸 grid 卡片，不在一张大 SVG 内另画宫格。
- 参数蓝紫、激活绿、聚合黄、梯度青、优化器灰。并行分布颜色放在独立位置，不覆盖数据角色。Layer Stack 容量视图沿用自身的权重粉紫色，是明确的来源变体，不将其推广为全库新色板。
- 展开数值向量一格一个元素、固定格距，长度随数量变化；教学纹理网格不声称格数等于真实 shape。灰度采样亮度表达绝对值幅度，不表达正负；异常橙红仅定位异常样本。
- Add 与 Multiply 均为直径 48 的圆，符号使用 2 单位线描，不能因字体字形改变大小。
- 计算保留胶囊，各已确认操作变体按对应 SVG 复用；通信保留虚线轮廓。不要用统一矩形替换所有对象。
- Kernel 为圆角容器、10% 白色填充、黑色目标标识，内部容纳 OP；普通函数不等于设备入口。
- Task 与设备指令采用亮绿 #9EF04B 的 260×60 实心矩形、黑色方形图标底与 20px 名称。Task 为调度图标，指令为终端图标；两者语义层级不同。使用“任务 0”等可理解名称，不使用未定义 T0。
- Rank 的平面两种表示共用相同轮廓、四角圆点和底色。2.5D Rank 保留正交投影、面明暗、贴面文字、容量比例；异常分片的位置可能是模拟，不能当真实地址。
- 连续 Forward 是 >>>>>>>，Backward 是 <<<<<<<，使用同一折线沿路径排列、水平镜像。它们不同于层内实线／虚线依赖，也不是时间轴。层间激活梯度 dL/dh 不等于参数梯度 dL/dW。
- 分块状态：归约完成与未完成归约共用同色、同尺寸、同元素数量的向量；通过边框和底色强度区分。未完成值可为本地贡献或部分和，不等于未选中、未参与或通用“弱化”。
- 不添加通用业务状态 tag 或外置 UI 选择标记。需要的业务状态直接使用已确认图元变体。
- 关系保留各自方向、端点、虚实线及来源语境，不能因统一风格把存储绑定变成执行箭头。参数读取已有两种来源表示，不能无说明地混用。
- Pattern 单独组织：参数化计算、分片/复制/部分结果、值/视图/存储、残差旁路、层内紧凑/展开。展开应保留对象 ID、总布局和真实形状约束。原 demo 的 mHC 旁路不是普通单流恒等连接。

## 验证

运行 `python3 scripts/validate_approved_glyphs.py` 检查 SVG 可解析性、唯一 ID 与文件指纹。该检查不是浏览器视觉验收。更新基线时同步 manifest、SVG、离线库与本文件；不能将提取页或拒绝的候选当正式来源。
