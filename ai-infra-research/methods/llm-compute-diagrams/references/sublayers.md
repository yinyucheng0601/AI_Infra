# 子层、Dense/MoE 与残差

## 组织 Dense 与 MoE 对照

先建立子层输入、输出及外层残差边界，再展开内部。Dense FFN 可用 token 行和特征维的变换讲清逐位置计算；具体升维、门控、激活函数和投影数量以实现为准。

MoE 建议沿同一批示例 token 展开：输入 → router 分数 → top-k 选择及权重 → 按专家分发 → 专家计算 → 返回与加权合并 → 恢复 token 顺序和输出 shape。用少量 token 与专家示例说明机制，明示示例规模。token 可能送往多个专家；每个被选中的专家处理的是 token 的特征向量，而非默认把特征维切成 top-k 份。

路由系数是输入相关的中间结果，router 自身参数是可训练权重，两者分开画。合并方式、容量限制、丢弃或无丢弃路由、共享专家、负载均衡损失等均按来源选择性展开。只在任务需要时引入专家跨设备部署；语义路由图不自动等于网络通信图。

对照同一输入输出边界下，Dense 的共享计算与 MoE 的按 token 选择专家，解释总参数量、单 token 激活参数量与实际开销之间的区别。不要仅凭专家数推导等比例加速。

## 普通层的边界

对普通 Pre-Norm 基线，明确：

- Y = X + Attn(Norm₁(X))。
- Z = Y + FFN(Norm₂(Y))。
- R_Attn 与 R_FFN 是分支输出；Y、Z 是残差合并后的输出。
- 第二条旁路传递 Y。加法两侧 shape 相同，通常都为 T×H，batch 维可标明已省略。
- 反向同时沿分支和旁路传播，在共同输入处汇合；参数梯度与激活梯度分开解释。

## mHC

只在来源支持时使用具体扩展倍率。n=4 表示每个 token 持有四个 H 维向量；H_pre 读取为一路，计算分支处理该向量，H_post 将输出写回四路，H_res 混合旁路四路状态。Attention 与 FFN 各自可配这样的连接。

连接系数可随输入动态生成，其生成参数与运行时系数分开。H_res 的双随机约束作用于残差混合，不能推导出整个网络永不放大、所有梯度永不衰减、或残差扩展免费带来四倍能力。用正面文字说明受控混合的性质和新增状态、访存等开销。

需要解释具体实现时核对原始论文 https://arxiv.org/abs/2512.24880 及指定实现，不把示例复用为其他模型已采用 mHC 的证据。
