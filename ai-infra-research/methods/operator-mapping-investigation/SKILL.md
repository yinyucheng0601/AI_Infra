# 算子映射调查

输入是算子仓库与版本、当前用例和具体疑问。先从会话/代码推导缺失参数，仅对阻塞项提问。固定生效 Host / Kernel 分支，区分数学应有集合、源码请求、参与计算、写回与设备观测。

读取 [建模与验证流程](references/mapping-workflow.md)。输出可脱离渲染运行的模型、稳定对象 ID、带文件/行号/revision 的证据、分析条件与未确认项。最小字段与交接约定由总 workflow 的 task-contract 定义；独立使用时输出等价的结构即可，不依赖界面。

地址和索引必须带单位及坐标范围；将请求槽、目标槽和消费集合分别建模。不为图面完整补出未知 API 行为，不因额外请求直接宣布 bug。无实测数据不推断流水持续时间或瓶颈。

先检查普通与边界对象，再扩展覆盖。用独立参考验证地址、集合、遗漏/重复与写回；声称同类参数化前验证另一合法配置。CPU/静态检查不代替 NPU 运行。

有可靠参考和已确认的实现适配时，主动比对并输出核查候选，而不是要求用户先提出全部问题。每个候选包含稳定 ID、对象/阶段、预期与实现侧范围、单位、固定版本证据、成立前提和下一步验证问题。参考与实现侧计算应能独立核对，不能用同一公式自证；用已知边界或人为注入差异验证检查能检出问题。

分别报告数学模型差异、源码参数构造差异与设备观测。API 实参的数值包络不等于实际访存范围；语义未确认时只输出条件候选，并列出需要的 API 版本或设备实验。固定版本适配器声明覆盖的分支和配置，未覆盖不是通过；没有差异时报告已检查范围，不制造告警或宣称 Kernel 已正确。

后续可交给 ai-infra-glyphs 选图元、observability-design-style 组织证据、design-spatial-systems-ui 呈现。仅要求分析时到模型和证据即止，不擅自生成网站或修改算子。

复核外部扫描候选时，保留原始结果并追加独立判断：追查控制流、调用方与 helper，而非仅重述扫描消息；判断绑定源码版本与成立条件。已排除只针对具体指控，无法确认时列出缺失证据。向工作台提供可达配置/Task/步骤绑定；不可达不编造示例配置。
