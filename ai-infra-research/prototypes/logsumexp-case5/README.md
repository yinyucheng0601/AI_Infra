# LogSumExp Case5 · 独立调查原型

打开 `index.html` 即可离线使用，约 138 KB，无外部脚本、字体或网络依赖。源码链接联网查看；同一固定版本的代码行已内嵌，可离线展开。

整屏无限画布：左侧输出坐标矩阵关联中央 7×27 输入集合，选择一个输入后，在同一空间显示其所属 GM 搬运块、紧密 UB 排列和 work 归约列。GM 行间留出间隔，UB 和 work 紧密排列；位置关系体现源 stride 与目的整理。b=16/11 分块直接由输入集合下方边界选择，尾列额外请求贴在源列上。

拖动平移、滚轮以指针为中心缩放，右下角适应范围；选择、浮层开关均保留视角。默认 y[0,0] 显示“先点一个绿色输入”引导，可一键追踪 x[2,8,0,0]；右上“查看尾块差异”定位 d=38。红列直接标为“d=39 · 额外请求 / 未参与归约 · 设备行为待确认”。默认检查器关闭，点击对象后打开紧凑证据浮层；源码、公式、边界和调查问题按需展开。上下文序列化仍使用独立 model.js。

## 文件

- `ANALYSIS.md`：先于页面完成的源码分析、推导前提、待确认差异和设计候选。

- `verify.cjs` / `validation.json`：全量验证脚本与本轮机器可读结果。
- `preview.png`：实际 Chrome 最终无限画布检查截图。
- `liquid-glass.js` / `liquid-glass.css` / `LICENSE`：Spatial Systems 已确认外围控件材质，内嵌到离线页面；保留 MIT 许可。

## 重建与验证

在此目录运行：

```sh
rtk python3 build.py
rtk node verify.cjs
rtk python3 serve.py
```

模型明确采用预期 `dim=[3,2], tileDim=[1,0]` 作为前提。固定 C++ 版本在有效 dim 后读取未初始化项，故无法仅凭源码确定所有真实执行分支。请求 d=39 超出合法轴范围；API 接受方式和硬件实际访问未知。详情见分析记录。

- 全部 2067 个输出、390663 个成员：每个输出恰好 189 个唯一合法输入；与独立扁平枚举参考一致，元素/字节偏移均校验。
