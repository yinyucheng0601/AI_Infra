# 协作约束

- 所有 UI 控件（含动态生成控件）必须提供单一 hover tooltip，并支持键盘聚焦触发；自定义 tooltip 与原生 title 不得叠加。底部同级工具栏统一高度与内部控件尺寸，不能让参数栏明显高于缩放栏。连线必须连接实际对象边界/端口，配置或分支变化后重新推导端点，禁止悬空硬编码线段。

- 选中态禁止使用 border、描边、外框或 box-shadow 圈选。Tab 必须使用胶囊形状，选中用实心高亮 fill 与深色文字；grid 选中及关联高亮使用高亮色 fill + 黑色文字，不以白色边框表示选中。键盘焦点采用可辨认的填充、文字或下划线反馈，不复用选中描边。此用户规则优先于 Skill 中泛化的选中轮廓建议。

- 用户明确要求：可视化页面禁止出现“教学模拟”“教学纹理”“仅作教学示意”等同义说明或免责声明，包括图内标签、图例、悬浮提示和抽屉说明。不要反复添加此类注释。数据推导、来源与假设在实现及内部文档中保持准确，不得将推导值冒充实测值；需要解释数值时使用具体的 shape、dtype、分片规则与计算口径。

- 本仓库服务设计成果盘点、内部汇报和团队资产积累，不收纯后端、算法实现或无设计贡献的开发项目。
- 按资产而非整项目判断收录范围。技术工具中有价值的设计流程可以收录，后端实现不必搬迁。
- 不把 profiling report 自动标记为白皮书；model_skill-dss3.2new 下内容不得纳入白皮书分类。
- 不批量复制候选扫描结果、第三方示例、依赖、历史副本或本机 Skills。
- 不修改来源仓库，不创建远端或发布内容，除非用户明确授权。
- 正式展示不得依赖 /Users/... 或 .local-*；来源未解析时明确标记，不伪造 URL。
- 分别记录内容成熟度与验证证据；文件存在不等于可运行、可复用或已验收。
- 已有首批知识库页面。视觉页面优先复用已有系统；Web、Vue、TUI 不强行共用一套实现。
- catalog/assets.json 是唯一目录源；页面源在 web/，通过 scripts/build.py 生成首页及 PTO 兼容入口。禁止分别手改生成文件。
- 预览服务只绑定回环地址并使用文件白名单；不得为方便访问而开放整个家目录或所有仓库。
- 不默认运行浏览器自动化或截图；由用户进行视觉验收，除非明确要求自动验证。
- Shell 命令使用 rtk 前缀。修改后执行目录校验。
- CSA Pass Field 唯一源码在 `PyPTO3-main/Design/csa-pass-field`；`patterns/csa-pass-field/index.html` 是自动构建产物，禁止直接编辑。运行 `scripts/build.py` 自动收录；来源/输入指纹和产物哈希见同目录 manifest。流程见 `patterns/csa-pass-field/README.md`。
