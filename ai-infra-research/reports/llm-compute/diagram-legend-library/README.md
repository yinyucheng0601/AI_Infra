## 来源与维护

- `inventory.json` 记录来源文件指纹、图例说明与来源关联。
- `build.cjs` 调用原报告图元生成函数，按固定示例尺寸抽取 SVG；包含用于说明对象的最小组合。
- 同一图元的多次出现归并；专题画法、对象层级和状态差异保留。
- 不将所有具名算子或完整机制图当作独立图例。页面收录的是报告采用的表达方式，不宣称为行业标准。
- 当前已定稿 Library 报告可能仍有历史色值差异；保留实际来源，未将 Skill 的新增配色反向套入源报告。

构建：`rtk node build.cjs`。校验：`rtk node validate.cjs`。

本次检查来源完整覆盖、指纹、链接、SVG XML、标记引用、脚本与模拟 DOM 交互。按仓库约定，视觉验收由用户执行；未运行浏览器自动化。
