## 不止阅读，进入系统内部

AI Infra 是一个持续生长的 AI 基础设施设计研究与交互作品集。它把分散在架构图、代码和技术文档里的信息，组织成可以浏览、操控和逐步理解的体验。

- **看清结构**：从集群、机柜深入到抽屉、组件与封装，建立宏观系统与微观部件的联系。
- **跟随过程**：沿着模型计算、编译变换和通信流程，观察对象及其关系如何变化。
- **沉淀表达**：将图解、空间布局和交互方法整理为 Patterns 与 Skills，连接研究和设计实践。
