# 框架试验测量

注意：以下是补齐原版焦点/FLIP 动效之前的旧测量，不用于当前版本选型。

本机 Chrome、1440×810、开发服务器、每框架三个全新浏览器上下文。页面：language → agent → system → agent → language。

|框架|完成次数|load 中位 ms|帧间隔 p95 中位 ms|长任务次数中位|最终 JS heap 中位 MB|
|---|---:|---:|---:|---:|---:|
|slidev|3|290.8|16.8|3|37.0|
|reveal|3|46.3|16.8|2|22.4|

限制：load 不等于 iframe 可交互；heap 不包含完整进程/GPU占用；帧间隔包含静止等待，不能等同动画 FPS。开发构建、样本组件挂载策略不同，不能据此宣称某框架整体更快。

已通过：两套框架 Scale 输出 10.5/-11 → -13.5/8；三个真实 iframe 均加载，DOM 元素数 438/183/1710；页面无 JS 异常。

待验收：完整 FLIP/自动播放、iframe 内控件与键盘焦点、离页暂停与资源释放、文字编辑保存、生产构建及原版基线。

架构建议：正文与讲稿逐页外置；交互场景独立组件；大型 iframe 按需挂载、邻页预加载、离页显式暂停。当前尚不据性能选择唯一框架。
