# 对象与视觉语言 v1

此版本作用于图例库的新「统一对象与组合」层。历史报告和 47 个来源图例保持原样；统一规则不是对历史画法已经一致的声明。

## 数据契约

对象记录与显示记录分开保存。不同语义层级通过有依据的 mapping 关系连接，不仅因名称相同而合并身份。

```js
const object = {
  id: 'value-0', kind: 'value', scope: 'model/linear-0',
  label: 'X', shape: [2, 4], dtype: 'FP16', role: 'activation',
  provenance: [{report: 'pypto-compilation-guide', anchor: 'inherited'}]
};
const presentation = {
  expanded: true, parallel: 'TP', placement: '分片',
  // 业务状态与 UI 选择不作为通用装饰绘制
};
// VisualSystem.data(object, x, y, presentation) -> SVG group
```

`id` 在所属范围内稳定；全局引用使用 `scope + id`。折叠与展开保留 ID 和元数据。矩阵 [2,4] 与向量 [6] 是两个独立形状示例，分别使用 value-0 与 vector-0，切换示例不是 reshape 操作。数值向量一格一个元素；没有 values 的矩阵只表达行列，不声称具有数值证据。

数据角色不产生新的对象类型。Tile 可以作为值的编译层级与形状/空间元数据；Token 的离散标识仍在来源层单列，不冒充特征向量。视图以 kind=view 表达索引关系，底层分配以 kind=storage 表达存储身份。示例不宣称这些字段就是某编译器的真实 schema。

## 构造规则

- 值折叠为 160×64；无缩略网格数量暗示。名称 14、shape 12，内部角色条宽 4。
- 展开格距固定 24、元素方格 20。宽=列数×24，高=行数×24。向量 [6] 是 [3] 的两倍长。外层 SVG 等比缩放；同一组合图共用尺度。
- 计算/通信胶囊 260×48，18 号居中文字；加法 38 圆、乘法 48 圆。
- Function/Kernel/Rank/分配保留名称栏容器；Task 圆角卡片；Loop 左括线；MemRef 两侧内竖线；指令与 Pass 180×32 窄条。家族尺寸相同不代表语义相同。
- 角色色：内部条或元素格；并行色：外侧括线及文字。沿用确认的五种数据角色与 DP/TP/SP/CP/PP/EP 色板，不用选中颜色覆盖数据。
- 不添加通用业务状态 tag 或外置选择角标。已完成归约、未参与路由等历史业务表示保留在来源图例，按原场景理解。
- 数据依赖用开口箭头；调用用长虚线；绑定用圆端点；跨阶段对应用点线菱形。剩余历史关系仍可在来源层检索。

## 组合模式

1. 参数化计算：X [2,4]、W [4,3] → MatMul → Y [2,3]。参数边接到操作上方，激活边左右流动；展开共 26 个格子。
2. 分片/复制/部分结果：两个 Rank 的相同布局。W [4,4] 按列切成两个 [4,2]；复制保留两个完整 [4,4]；K 维分割的 MatMul 产生两个 [2,4] 部分结果，需要逐元素求和。后者不等于输出的互斥分片。
3. 值/视图/存储：V [4,4]、FP16、连续行布局，32 B。后两行视图 [2,4] 经独立 MemRef 引用 B0 的 [16,32) B。表示绑定，不表示拷贝或先后执行。

## 复用与验证

`visual-system.js` 无 DOM 依赖，可 CommonJS 引入，也可内联为浏览器 VisualSystem。tokens、data、node、edge、wrap、render 是共用接口；`system-catalog.cjs` 维护规则条目与历史图例对应。`template.html` 保留检索、来源筛选、详情与当前 SVG 导出；构建时把渲染器和历史 SVG 全部嵌入单文件。

运行 `node build.cjs` 与 `node validate.cjs`。验证包括来源指纹、链接、检索与过滤、详情键盘、原生控件不拦截、示例元素数/长度比例、角色色与分布色共存、无通用状态标签和选择装饰、视图身份与当前导出链接。自动验证为静态与模拟 DOM；视觉验收仍需用户在页面中确认。
