# PPT 本地预览工程

1. 解压整个文件夹，保持目录结构。
2. 新电脑安装 Node.js 22 LTS（https://nodejs.org/）和 Python 3。
3. macOS 双击 `启动PPT.command`。首次启动会联网安装依赖，之后自动打开浏览器。
4. 保持终端窗口打开，按 Ctrl+C 停止服务。若 8854 被占用，会自动选择空闲端口。

如果 macOS 阻止打开，右键文件选择“打开”；若执行权限丢失，在终端运行 `chmod +x 启动PPT.command`。
Windows / Linux 可以在文件夹中运行 `python launch-preview.py`（Windows 也可以用 `py launch-preview.py`）。

源码入口：`presentation/slides.md`；完整讲稿：`presentation/speaker-notes-current.md`。
包中包含源码、图元和静态发布版本 `ppt/`；不含 node_modules、Git 历史、备份或评审文件。
