# PanGu · Layer Atlas

以 49 层空间堆叠联动张量采样、训练阶段与 Rank 内存，提供从模型总览到矩阵详情的交互 Pattern。

## 交互内容

- 2.5D / 侧视图切换与逐层导航。
- 激活、参数梯度、权重观测与异常定位。
- 矩阵缩放、采样统计与传播路径教学模拟。
- 单 Rank 内存及全部 Rank 抽屉联动。

## 来源与边界

入口为仓库内 `layer_stack/pangu-layer-stack_副本.html`，直接复用原目录内的 CSS、JavaScript 与内存总览页面，不复制维护第二份实现。

数据与传播过程为教学模拟，不代表整网实测。2026-09-28 完成收录与静态引用检查；未进行浏览器视觉验收。
