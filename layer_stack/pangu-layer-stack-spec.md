# PanGu Layer Atlas — 页面规格说明

版本：1.0  
日期：2026-09-17  
对应实现：`pangu-layer-stack.html`，页面版本 14  
用途：作为设计与前端交接依据，记录当前模型设定、数据口径、视觉编码、交互及实现边界。

## 1. 产品目标与范围

页面用于从全部模型层定位某一层，再查看该层一个指定张量的数值分布。左侧用 2.5D 堆叠表达层序，右侧将所选层的同一张矩阵平铺并显示数字，底部用柱状图比较不同层同类张量的整体幅度。

三个模式分别回答：权重——输入特征怎样参与输出计算；参数梯度——对应参数怎样影响损失；激活——这次输入计算出了什么。三种模式共用几何布局，但张量含义、轴语义及统计解释不同。

当前原型是单一静态快照，不含 Step、时间播放、Rank 选择、性能 trace、专家负载、优化器实际更新量或自动异常判定。每层展示的是 Query 降维投影的代表性张量，不是整层所有参数，也不是整个 MoE 的专家矩阵集合。

## 3. 三类张量与轴定义

| 模式 | 符号 | 逻辑形状（行 × 列） | 行 | 列 | 逻辑元素数量 |
| --- | --- | --- | --- | --- | --- |
| 权重 | W | 1024 × 2560 | 输出特征 0–1023 | 输入特征 0–2559 | 2,621,440 |
| 参数梯度 | dL/dW | 1024 × 2560 | 与 W 相同 | 与 W 相同 | 2,621,440 |
| 激活 | H | 32768 × 1024 | Token 位置 0–32767 | 输出特征 0–1023 | 33,554,432 |

权重与参数梯度必须逐坐标对应；激活的行表示输入序列位置，不能解释成权重矩阵的输出特征轴。激活这里具体指所选 Query 降维线性投影的输出，不能泛指整层所有中间结果或 Attention 概率。

页面用 token 位置编号，不展示自然语言 token 文本，也没有 tokenizer 映射。激活可为正或负。

## 4. 数据规格

### 4.1 数据性质

所有数值由本地确定性公式生成，不是实际训练观测，不来自 checkpoint，也没有联网采集。权重、梯度与激活各自生成用于演示的分布，形状和坐标能够对应，但梯度并不是由这组权重实际反向传播得到，激活也不是对实际输入完成矩阵乘法的结果。

每个模式、每一层都有一张 64×64 的采样矩阵，共 4096 个数值；总数为 3×49×4096 = 602,112 个模拟采样值。“完整采样矩阵”指显示这 4096 个值的全部，不是展示原逻辑张量的数百万个元素。

### 4.2 采样坐标映射

令采样行、列分别为 r、c，范围均为 0–63。

| 模式 | 逻辑行坐标 | 逻辑列坐标 | 最后一个采样坐标 |
| --- | --- | --- | --- |
| 权重 / 参数梯度 | 16r | 40c | (1008, 2520) |
| 激活 | 512r | 16c | (32256, 1008) |

采样是等间距覆盖整个维度范围的示意，不包括每个维度最后一个元素；轴说明中的 1023、2559、32767 是逻辑范围上限，不代表这些位置已采样。正方形显示格子不代表真实张量是正方形，也不代表行列采用相同采样间隔。

源码内部仍将数据存为 16×16 组、每组 4×4 个值，以兼容统计计算。这个组织方式不再作为 UI 分块，也不能重新将左侧画成 16×16 摘要图。

### 4.3 生成方式（复现依据）

以层编号 l、采样坐标 r/c 定义 `u = 24r/64`、`v = 24c/64`：

```text
z = sin((u+1)×12.9898 + (v+1)×78.233 + l×4.193)

weight_base = 0.024z + 0.012 sin(0.3u + 0.15v + 0.09l)
gradient_base = 0.0005z
              + 0.006 exp(-((u-8)/3)² - ((v-16)/3)²)
                      × exp(-((l-18)/6)²)
activation_base = 0.4z
                + 1.1 sin(0.7v + 0.04l) × exp(-((u-12)/3)²)
                + 0.15 sin(0.5u)

value = base × gain
gain = 1 + amplitude × exp(-((l-center)/2.2)²)
```

| 模式 | center | amplitude |
| --- | --- | --- |
| 权重 | 34 | 1.25 |
| 参数梯度 | 18 | 2.8 |
| 激活 | 29 | 1.25 |

这些是人为加入的幅度增强中心，用于使演示中不同层存在差异，不是实测异常层，也不是告警阈值。实际最大 RMS 层应由计算结果确定。

### 4.4 统计口径

所有统计只使用当前层、当前模式的 4096 个采样值。RMS 为均方根：

```text
RMS = sqrt(sum(x²) / 4096)
mean = sum(x) / 4096
negative_fraction = count(x < 0) / 4096
relative_gradient = RMS(gradient) / RMS(weight)
```

右侧展示采样数、RMS、带符号均值、最小值、最大值和负值比例。梯度模式额外显示梯度 RMS / 权重 RMS；该比值不等于实际参数更新比例。最小与最大值也只针对采样集，不能宣称是全量张量的极值。

一般统计数值保留 4 位小数；非零且绝对值小于 0.001 时使用科学计数法。右侧格内权重和激活保留 3 位小数，梯度使用科学计数法；悬停读数显示 6 位有效数字，避免仅依据格内舍入数字判断零值。

## 5. 视觉编码与跨视图一致性

### 5.1 同一数据源

必须满足：`左侧(layer, row, col) = 右侧(layer, row, col)`。矩阵中每个格子都表示单个采样值，两边共用取值函数 `sampleAtLayer` 和颜色函数 `sampleColor`，禁止左右分别生成随机数据、转置、排序或独立归一化。

左侧没有数字，右侧有数字与坐标。透视、遮挡、缩小插值和文字覆盖会改变屏幕上的局部观感，但不能改变格子底色的计算依据。

### 5.2 灰度色标

对一个模式，取全部 49 层采样值的最大绝对值作为上限 M。切换层不改变 M；切换模式重新选择该模式的 M，因此不能用模式间相同亮度比较原始数值。

```text
t = clamp(abs(value) / M, 0, 1)
color = interpolate(#333333 → #505050 → #888888 → #BCBCBC → #EEEEEE, t^0.8)
```

色标范围从 #333333 到 #EEEEEE，数值绝对值越大越亮；正负号通过右侧数字表达。`t^0.8` 是当前的非线性显示映射，不是线性灰度。

未选中层边框和柱体颜色使用 `RMS/M` 代入同一灰度函数。选中层的外边框固定为 #FFFFFF，优先表达选中状态，不再承载该层的 RMS 大小。

### 5.3 柱状图

每根柱表示该层 Query 降维投影当前所选张量的采样 RMS，柱高为：

```text
height = 76px × layer_RMS / max_RMS_across_49_layers
```

所有柱共用零基线。最高柱表示当前模式下 RMS 最大，不是单个最大元素、百分比、重要性或异常评分。右侧“最高 Lx · RMS …”显示最大统计量所在层；若并列，当前实现取第一个。仅选中柱顶部常驻数值，其他柱可通过悬停查看。选中状态不修改柱高。

### 5.4 指标解释（放在图例提示）

| 对象 | 高幅度意味着什么 | 开发者需要进一步观察什么 |
| --- | --- | --- |
| 权重 | 参数整体幅度较大，也可能由少数大值抬高 | 分布偏移、局部极值、实际更新相对权重的幅度 |
| 参数梯度 | 损失对参数的局部导数整体幅度较大 | 梯度相对权重大小、是否接近零或出现非有限值，以及历史变化与损失 |
| 激活 | 中间特征数值幅度较大，不等于 token 更重要 | 是否逐层放大/衰减、是否集中在少数 token 或通道，以及数值稳定性与低精度表示范围 |

本页没有历史基线、告警规则或真实训练证据，不能自动把亮区标为“异常”。上述文字解释观测用途，不表示这些诊断能力已经实现。

## 7. 2.5D 几何规则

总览 SVG viewBox 为 `0 0 1400 850`。每张层平面局部尺寸 300×300，矩阵纹理在 `(31,43)`，大小 240×240。

```text
projectionX = 0.72
projectionY = 0.46 × 0.72 = 0.3312
x(layer) = 170 + 20 × layer
y(layer, selected) = max(45, 365 - 6 × layer - (selected ? 155 : 0))
transform = matrix(0.72, 0.3312, 0, 1, x, y)
```

这是固定平行投影式 2.5D 示意，不含自由旋转摄像机。横向系数经过视觉调窄，格子在本地平面为正方形，投影后不会是屏幕上的正方形。

绘制顺序固定为 L48→L0，靠前层自然遮挡靠后层。选中层只向上抽出，禁止最后重绘到所有层之上，也不能为了完全可见而破坏遮挡关系。

标签贴近选中层左上侧：主标签位于 `(x-43,y+9)`，右对齐；副标签位于 `(x-43,y+34)`；短连接线从 `(x-32,y+18)` 到 `(x,y+18)`。标签与平面同步移动，不固定在页面远端。

所有层边框始终为 1.5px，使用 non-scaling-stroke；选中不增粗。层间 x 间距 20、y 间距 -6 均为 SVG 坐标值，实际屏幕距离随容器缩放。

| 次文字 | #A0A0A0；局部 #AAAAAA |

### 8.2 排版与形状

正文使用 Inter 优先的系统无衬线字体栈，未加载外部字体；数值与索引使用 ui-monospace/monospace。标题字重 500，正文通常 400。桌面主标题 25px、右侧标题 20px、说明 12–13px、尺寸 17px、柱顶值 11px。层号及部分辅助信息为 10px，当前属于高密度原型设置。

矩阵格子为直角，层平面为直角；按钮只使用约 3–5px 小圆角。尽量通过留白和细分隔线组织内容，不添加多层卡片、装饰边框或大面积阴影。长解释进入图例 hover，不挤占主体。

右侧矩阵 SVG viewBox 为 2110×2110，绘图区从 `(62,62)` 起，每格占 32×32，实际填充 31×31，留 1 单位间隙。数字字号 6.3 是 SVG 坐标单位，不是最终屏幕像素；适应宽度时只能看分布，阅读数字应依赖放大或悬停读数。坐标刻度每 8 个采样位置显示一次。

### 8.3 可复用设计要求

其他场景沿用本风格时，应保留中性黑白配色、单一主要可视化、紧凑的边缘控件、可辨识灰度、近端标注与短连线。2.5D 只在需要表达结构层次时使用；数据对象不同可以换图形，但选中语义、数值尺度和留白原则保持一致。

## 9. 实现与数据一致性约束

页面为单个离线 HTML，内嵌 CSS/JavaScript，无外部运行时依赖。总览使用 SVG 层平面和本地 Canvas 生成的 PNG 纹理；右侧使用 SVG 格子与数字。每层纹理为 512×512，采样格占 8×8、填充 7.75×7.75，与右侧 31/32 的填充比例一致。纹理按模式与层缓存。

关键函数为 `makeData`（生成采样）、`sampleAtLayer`（统一取值）、`sampleColor`（统一颜色）、`layerTexture`（总览纹理）、`drawWhole`（右侧矩阵）、`drawMatrices`（全层更新）、`choose/redraw`（选层联动）。

后续如果接入动态数据，纹理缓存键必须加入快照或数据版本，或主动清空缓存；当前 `mode:layer` 缓存键仅适用于不变化的模拟数据。

## 10. 验收标准与现有边界

### 已按逻辑验证的要求

- 49 层完整存在，L0/L48 边界导航正确。
- 权重、参数梯度、激活三个模式下，选层后标题、右侧数据和柱值同步更新。
- 右侧每层恰好有 4096 个有限采样值，且按原行列顺序排列。
- 4096 个值直接计算的 RMS，与右侧统计及底部柱状图数据相等。
- 左右采用同一 `sampleColor`，对选定层与坐标检查时颜色输出一致。
- 右侧不再存在分块选择或局部窗口；适应宽度时展示整个采样矩阵。
- 默认无 Step 控件，也不恢复顶部模拟数据徽标。

### 仍需浏览器验收 / 尚未实现

已有验证主要为脚本解析和模拟 DOM 的逻辑检查，不能替代真实浏览器截图验收。需在桌面和窄屏检查纹理加载、文字可读性、遮挡、提示框裁切、侧栏滚动与缩放。左右底色算法相同，不承诺透视缩小后的屏幕像素逐点相同。

当前没有全量张量加载、样本/token 文本选择、实际训练数据导入、时间基线、非有限值展示、告警或全键盘矩阵导航。若接入真实数据，需补充缺失、未采集、不适用和 NaN/Inf 状态，不能把它们统一画成零值。

## 11. 后续真实数据接入建议（非当前已实现）

每张张量至少提供：模型版本、层编号、张量名称与计算位置、类型、逻辑 shape、观察时间/快照标识、样本编号、采样行列索引、采样值、采样方法、全局/分片范围及数据状态。时间信息可以作为数据元信息保留，不必恢复 Step 控件。

输入值应只进入一份共享数据模型，再驱动两张矩阵和柱状图。跨层比较需保持张量角色、采样方法与统计范围一致；真实分布的健康程度必须结合基线与上下文判断，不能把原型的人为幅度增强中心当作异常规则。
