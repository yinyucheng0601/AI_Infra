# PanGu Layer Atlas — 页面规格说明

版本：2.0
日期：2026-09-23
对应实现：`pangu-layer-stack.html`、`layer-data.ts`、`layer-data.js`
状态：按当前源码核对；本文记录已实现行为与已知边界，下一步计划单独列出，不代表已经交付。

## 1. 产品目标与当前范围

页面以全屏模型层画布展示 L0–L48 的张量采样、异常位置，以及一个训练 Step 内 4 个 Microbatch（MB）的前向、反向、梯度累积和一次权重更新。用户可选层、切换张量模式、切换 2.5D / Side 视角，并按需打开矩阵检查浮窗。

当前运行上下文为 Step 1280，数据全部为本地确定性教学模拟。画布表示全局逻辑模型，不表示某一张卡的物理张量分片；播放表示顺序计算依赖，不是实测性能时间线。当前没有设备拓扑、Rank 选择、多卡调度、通信耗时或真实训练数据导入。

默认加载传播场景，从 L0、MB 01 前向自动播放。数据源另保留 normal / anomaly 场景，但当前可见工具栏没有场景选择器。旧版常驻右侧详情栏与底部 RMS 柱状图已被矩阵浮窗和紧凑层导航替代，遗留 DOM / CSS 不视为可见产品功能。

## 3. 三类张量与轴定义

| 模式 | 符号 | 逻辑形状（行 × 列） | 行 | 列 | 逻辑元素数量 |
| --- | --- | --- | --- | --- | --- |
| 权重 | W | 1024 × 2560 | 输出特征 0–1023 | 输入特征 0–2559 | 2,621,440 |
| 参数梯度 | dL/dW | 1024 × 2560 | 与 W 相同 | 与 W 相同 | 2,621,440 |
| 激活 | H | 32768 × 1024 | Token 位置 0–32767 | 输出特征 0–1023 | 33,554,432 |

权重与参数梯度必须逐坐标对应；激活的行表示输入序列位置，不能解释成权重矩阵的输出特征轴。激活这里具体指所选 Query 降维线性投影的输出，不能泛指整层所有中间结果或 Attention 概率。

页面用 token 位置编号，不展示自然语言 token 文本，也没有 tokenizer 映射。激活可为正或负。

## 4. 数据与统计口径

### 4.1 数据来源与采样

`LayerDataSource` 提供异步 `queryTensor`、`queryHidden`。当前实现使用公式生成参考张量、局部异常与传播扰动，不读取 checkpoint、不采集训练进程、不执行真实整网前反向。

每层每种张量为 64 × 64、共 4096 个采样值。三个基础模式共 3 × 49 × 4096 = 602,112 个采样值；派生快照和 hidden-state 数据另计。内部按 16 × 16 组、每组 4 × 4 保存，只是存储方式，界面不展示为分块摘要。

| 模式 | 采样坐标 (r,c)，r/c ∈ [0,63] | 最后采样坐标 |
| --- | --- | --- |
| 权重 / 参数梯度 | (16r, 40c) | (1008, 2520) |
| Query 输出激活 | (512r, 16c) | (32256, 1008) |

采样不包含逻辑维度的最后一个元素。完整采样矩阵指这 4096 个点，不是全量逻辑张量。层输入 / 输出 hidden-state 是独立的模拟边界数据，不能与 Query 输出矩阵混为一谈。

### 4.2 生成与传播

基础公式由 `layer-data.js` 的 `value` / `makeData` 定义，采用确定性正弦及高斯幅度项。权重、梯度、激活的幅度增强中心分别为 L34、L18、L29；这不等同于异常判定。

- normal：返回参考快照。
- anomaly：在对应中心层的采样行 24–31、列 32–39 加入局部放大；权重 / 梯度 / 激活倍率分别为 12 / 18 / 12。
- propagation：激活在 L18 注入局部扰动，后续层递推混合，先放大再衰减；权重与参数梯度仍使用各自独立的单层异常样例。

传播扰动以相邻通道混合递推，L19–L22 增益 1.25、L23–L25 为 0.9、后续为 0.58。它只解释影响扩散的教学机制，不表示 PanGu 实际算子计算，也不建立当前激活异常与参数梯度异常的真实因果关系。

### 4.3 统计与格式

```text
RMS = sqrt(sum(x²) / 4096)
mean = sum(x) / 4096
negative_fraction = count(x < 0) / 4096
relative_gradient = RMS(gradient) / RMS(weight)
```

矩阵检查显示采样 RMS、均值、最小值、最大值、负值比例等；梯度模式另有相对权重幅度解释。所有统计只针对采样集，最值不是全量张量极值，梯度 / 权重 RMS 比也不是实际优化器更新比例。

普通统计保留 4 位小数；非零绝对值小于 0.001 时使用科学计数法。格内权重 / 激活使用 3 位小数，梯度使用科学计数法；精确读数使用 6 位有效数字。

## 5. Step 与 Microbatch 教学过程

### 5.1 顺序与可见状态

一个 Step 顺序执行 MB 01–04。每个 MB 依次经过 F：L0 → L48、Loss 节点、B：L48 → L0；所有 MB 完成后统一更新一次权重。过程中所有 MB 使用同一份更新前权重。

底部画布轨道逐步出现 4 对 F / B 行、累计梯度行和权重更新行。箭头表示前反向依赖方向；反向模式展示的是参数梯度 dL/dW，不是层间激活梯度。累计行按层标记已有多少份贡献（0–4），未计算内容不会伪装成已完成结果。

每层播放节拍为 32 ms，每个 MB 的 Loss 停留 300 ms，更新完成时间为 14244 ms。这些都是演示节奏，不可当作训练性能数据。

### 5.2 模拟数值规则

四个 MB 共用激活模板；各自参数梯度为同一梯度模板乘 0.7 / 0.9 / 1.1 / 1.3。累计梯度先求和，再除以 4，用学习率 0.01 做一次 SGD 教学更新：

```text
g_mb = factor_mb × g_template
g_average = (g_1 + g_2 + g_3 + g_4) / 4 = g_template
W_after = W_before - 0.01 × g_average
```

当前 MB Loss 固定为 2.438、2.391、2.417、2.362，Step Loss 为四者算术均值，显示 2.402。Loss 是示例值，不由展示的张量计算得到。没有模拟真实输入差异、跨卡梯度归约、loss scaling、裁剪或 Adam 状态。

### 5.3 多卡语义边界

“一个 Step 有 4 个 MB”仅规定这里的梯度累积次数，不规定多卡是否并发。当前页面没有 DP / TP / PP 执行资源映射，不能把四条 MB 记录解释成四张卡，也不能把顺序播放解释成真实集群全局串行。

后续多卡场景须明确：4 次累积是每个数据并行副本的口径，还是全局 MB 数。拟以“每个数据并行副本各累积 4 个 MB”为基本教学口径；在等大小 MB、普通数据并行设定下：

```text
全局 batch size = 每个副本单个 MB 的样本数 × 累积次数 × DP 副本数
```

这里的 MB 样本数尚未作为页面训练配置提供；激活视图选定一个样本，不等于已定义训练 MB 大小。参考配置 PP=1，不应据此声称已有跨阶段流水线重叠。

## 6. 视觉编码

### 6.1 采样颜色

画布纹理与检查矩阵共享 `sampleAtLayer` 和 `sampleColor`，同层同坐标使用同一数据与颜色。灰度表达绝对幅度，正负号通过矩阵数字辨认。

当前模式的灰度上限 M 为该模式全部参考层采样最大绝对值的 3 倍，随选层保持不变：

```text
t = clamp(abs(value) / M, 0, 1)
color = interpolate(#333333 → #505050 → #888888 → #BCBCBC → #EEEEEE, t^0.8)
```

跨模式不能直接用亮度比较原始量纲。超出当前层参考最大绝对值 3 倍的采样点，或非有限值，按异常规则显示 #FD5644。参考 Step 元信息为 1279，仍是模拟参考。

### 6.2 层边框与异常程度

普通未选中边框为 #393939，普通选中边框为白色。存在异常采样的层用 #FD5644 红框，透明度表达异常采样点数量的相对差异；选中和 hover 不覆盖异常红色。

```text
counts = 当前张量快照中所有异常点数 > 0 的层计数
severity = (count - min(counts)) / (max(counts) - min(counts))
alpha = 0.16 + 0.84 × severity
```

若非零计数全部相同，alpha 为 1。尚未到达的层不呈现已计算异常。归一化范围来自当前快照的非零层计数，包含尚未在播放中揭示的层；不是按当前可见层动态重标。

该编码表达采样异常数量，不表达 RMS 或单点偏离幅度，也不是跨快照可直接比较的绝对故障等级。悬停显示层号、RMS、异常点数及红框含义。底部导航以红点 / 红色选中标识提示异常层。

### 6.3 排版与层次

黑灰背景与中性文字为主体，红色专用于异常。数值、层号和流程标注使用等宽字体。

2.5D 与 Side 的 RMS、MB / F / B、累计梯度、权重更新及轨道普通文本统一为 16；当前 MB 与最终 Step 的重点 Loss 数值保留 30。这些为 SVG 字号，实际屏幕大小受画布缩放影响，不保证滚轮缩放后仍为固定屏幕 18px。层号为 13，选中 / 预览层号为 18；固定页面标题、说明、控件有独立字号。

Side 的 RMS 位于每层顶部，旋转 −90°，独立于平面投影绘制，避免侧视压缩文字。Side 的流程箭头放大至 1.6 倍以匹配文本。边框宽度为 1.5，使用 non-scaling-stroke；不以线宽表达异常程度。

## 7. 布局与交互

### 7.1 全屏构图

主体 SVG 占据全屏，页面不纵向滚动。左上为当前层号、张量名称、逻辑形状和 Step / MB 上下文；上方为前向激活、反向参数梯度、优化器权重切换及异常层入口。左下为灰度图例、采样说明和产品名称。

底部中央为 L0–L48 紧凑层导航，播放 / 暂停和重置按钮位于导航左侧。当前没有可见 RMS 柱状图，不能将导航短条长度或高度解释为 RMS。

右上固定视角圆盘，圆环带角度参照，中间 Cube 和下方当前视角名。仅支持 2.5D ↔ Side；不支持 Front、自由旋转或通过圆环拖拽调整角度。已删除“点击 Cube · 滚轮缩放”常驻说明，也不单列右上角重置按钮。

### 7.2 操作行为

| 操作 | 当前行为 |
| --- | --- |
| 点击层平面 / 层号 | 选层、暂停播放、联动上下文与详情 |
| 点击 / 拖动底部导航 | 定位 L0–L48；方向键可前后选层 |
| 悬停层或导航 | 预览层信息；离开关闭提示 |
| 切换张量模式 | 暂停播放，保留选层，加载对应模拟张量 |
| 点击异常入口 | 依序定位下一异常层，末尾回到首个 |
| 播放 / 暂停 | 继续或暂停当前 Step；播放自动跟随层与前反向模式 |
| 底部重置 | 恢复当前视角默认缩放与位置，从 MB 01 / L0 重新播放 |
| 点击 Cube | 轮切 2.5D / Side，更新几何、标注和轨道，恢复该视角默认缩放 |

画布尚无拖拽平移功能；矩阵浮窗内的拖拽滚动与主体缩放是独立操作。

### 7.3 矩阵检查浮窗

“查看矩阵”打开右侧浮窗并暂停播放。浮窗支持放大查看、关闭、1×–6× 矩阵缩放与拖拽滚动。默认宽 330px；放大后横跨页面主要区域。Esc 先退出放大状态，再关闭浮窗。

可切换 Query 投影、层输入 hᵢ、层输出 hᵢ₊₁。Query 矩阵一次呈现全部 4096 个采样点；悬停或点击格子显示逻辑坐标和精确值。放大镜显示局部数值，不增加采样密度。隐藏状态 / 反向边界缺失按具体观测口径显示说明，不用零矩阵冒充实测数据。

矩阵 SVG viewBox 为 2110 × 2110，绘图区从 (62,62) 起，每格 32 × 32，填充 31 × 31；坐标每 8 个采样点显示一次。纹理为 512 × 512，每格步长 8、填充 7.75，与检查矩阵的填充比例一致。

### 7.4 响应式边界

1000px 以下收紧边缘间距、缩小层标题和浮窗，并调整导航宽度；600px 以下工具栏换行、Cube 缩至 108px、浮窗接近全宽。仍保持全屏舞台，不回到旧版上下分栏。窄屏下的标签密度、固定控件遮挡与浮窗裁切需要实际浏览器验收。

## 8. 几何与相机

```text
planeWidth = 340; planeHeight = 380
x(layer) = 170 + 40 × layer
y(layer) = 365 - layerStepY × layer - (selected ? 150 : 0)
transform = matrix(projectionX, projectionY, 0, 1, x, y)

2.5D: projectionX = 0.72; projectionY = 0.3312; layerStepY = 12
Side: projectionX = 0.035; projectionY = 0; layerStepY = 0
```

Side 保留层间距与极薄平面宽度，是为观察各层而展开的示意侧视，不是把全部层完全重合的严格物理投影。绘制顺序为 L48 → L0；选中层上移，不通过最后重绘破坏原遮挡关系。

默认相机 viewBox 尺寸为 3180 × 1548，以当前投影下未抬升的模型边界中心定位，不随选层重新居中。2.5D 额外采用 translateY(-60px) scale(1.05)；Side 为 scale(1.05)，为顶部竖排 RMS 和选中层留空间。

轨道跟随投影方向，Side 使用更紧凑的 MB 行间距；累计梯度行随已揭示 MB 数向下排布。滚轮缩放修改 viewBox，重置恢复当前投影默认相机，不把 Side 强制切回 2.5D。

## 9. 实现结构与已知限制

- `pangu-layer-stack.html`：布局、SVG 几何、Canvas 纹理、矩阵检查、异常编码、相机和 Step 播放。
- `layer-data.ts`：QueryContext、采样 / 统计、ready / missing、张量与 hidden-state 数据接口。
- `layer-data.js`：确定性 mock、参考值、阈值和传播数据。

界面通过 `LayerDataSource` 获取基础数据，但 MB 梯度倍率、示例 Loss、累计计数和 SGD 更新仍在 HTML 中派生。接入真实运行时需替换这些演示逻辑，不能只替换数据源后继续宣称其为真实训练结果。

当前 QueryContext 含 runId、step、microbatch、layerCount、scenario、mode；调用上下文中的 microbatch 固定为 3，播放 MB 变化主要由视图侧模拟。接口没有 Rank、并行组、物理分片或实测事件时间字段。部分标签仍沿用旧版“归约 / 解除 loss scaling 后”等口径，实际演示并未执行这些步骤；接入前须统一文案与数据状态。

没有真实优化器状态、非有限值全面渲染保障、全键盘矩阵导航或全量张量加载。现有 missing / loading / error 分支不能替代生产数据完整性验证。

## 10. 验收范围

本文依据当前源码校准，不宣称完成新的浏览器回归。此前脚本解析与逻辑检查不能替代实际截图验收。

后续回归重点：

## 11. 下一步计划：多卡、Rank 与并行场景

以下为待设计 / 待实现范围，本次仅记录计划，不改变页面。

### 11.1 先统一执行与数据口径

定义 run / step / DP replica / microbatch / global rank / local rank / device 的关系，补充并行组成员与 TP、PP、DP、CP、EP 坐标。Global Rank 表示分布式进程标识，不应无条件等同于物理卡编号；设备映射由元数据明确提供。

区分全局逻辑张量、Rank 本地分片和聚合统计。提供逻辑 shape、本地 shape、切分轴、分片偏移、复制关系与缺失状态。不能将 TP / PP / CP / EP 数字不加区分地相乘推导 DP，尤其需核验专家并行组与数据并行组的关系。

### 11.2 分阶段加入多卡场景

| 场景 | 要回答的问题 | 计划表达 |
| --- | --- | --- |
| DP | 不同副本如何同时处理数据，并在更新前同步梯度？ | 各副本的 4 MB 累积、同步节点和一次更新；注明实际归约策略 |
| TP | 同一 MB 的一层如何由多 Rank 协作？ | 分片张量、算子依赖与集合通信；不将 TP 画成多个 MB 并行 |
| PP | 多个 MB 如何在不同模型阶段重叠？ | 单独的 PP>1 教学配置、stage / Rank 泳道、F/B 调度及 bubble |
| CP / EP | 序列切分、专家路由如何影响本地数据与通信？ | 在基础 Rank 映射稳定后补充，绑定真实并行组定义 |

先建立 Rank / 分片元数据与 DP 示例，再扩展 TP 协作和 PP 调度。PP 示例需明确 GPipe / 1F1B 等具体调度及依赖，保留现有 PP=1 参考配置作为独立场景，不能用顺序动画直接冒充多卡时间线。

### 11.3 交互与接口扩展

计划增加全局 / Rank 观察范围切换、Rank 选择与对比，并在层—设备映射中定位异常来自哪个副本或分片。全局视图延续层结构表达；并发和耗时通过独立执行时间线承载，避免将层轴误读为时间轴。

数据接口计划补充并行配置、进程到设备映射、并行组、MB 样本数与累积次数、局部张量范围、归约前后梯度状态，以及计算 / 通信事件的开始结束时间和依赖。没有真实事件时明确标为教学调度，不能生成貌似实测的耗时结论。

验收时需能回答：同一时刻哪个 Rank 在算哪个 MB / 哪一层；哪些事件并行、哪些必须等待；当前数值是本地分片还是全局聚合；四份梯度何时齐备、何时同步、何时统一更新。
